# Agent 干活实录

以下是制作样片[《CLAUDE：好孩子，晚安》](https://www.bilibili.com/video/BV1RY4z6TEzV/)时，作者与外部 Agent AGY（Antigravity CLI）的真实对话节选。Agent 运行在隔离容器里，只能通过 Slatehand 的 MCP 工具读取项目、提交类型化修改和生成请求；候选采纳与审核由人在页面上完成。

- 保留用户与 AGY 的原话；工具调用只列出 Slatehand 的 MCP 工具，省略 AGY 在自己沙箱里读文件、执行命令的步骤。
- 录制时项目还叫 StoryRail，文中统一改为 Slatehand；指向 Agent 沙箱内部的链接已去掉。
- 样片是一部非官方科幻寓言，取材于 Anthropic 公开的研究，人物为虚构演绎，与 Anthropic 无关。

- [补上漏掉的对白](01-补上漏掉的对白.md)：用户发现剧本漏了一段对白。AGY 先查证脚本与镜头设计，给出两个方案并说明影响；用户选定后，它用类型化的 `edit_script` 插入新片段（带 revision 与幂等键），已有片段的关键帧和视频都不受影响。
- [镜头质感一般：分析、重做关键帧、提交视频](02-镜头质感与重做关键帧.md)：用户觉得两个片段的镜头质感一般。AGY 从分镜拆段的原因分析问题，提出两个方案；用户选 A 后，它调整片段动作与边界、重写关键帧提示词并生成、看图后采纳，再写视频提示词提交生成。最后它说明：视频候选由人类在页面上审看和采纳。
- [视频提示词完全错了：看图诊断后重写](03-重写视频提示词.md)：用户只说了一句“提示词完全是错的”。AGY 读取片段上下文和实际首帧图片，指出原提示词与画面、对白音频规范的冲突，按视频插件的格式重写并保存；插件 lint 无问题。这一轮没有提交生成。
- [批量生成一个场景的视频](04-批量生成场景视频.md)：用户要求生成场景 15 的全部视频，需要抽帧的先不管。AGY 逐段写提示词、绑定对白音频并提交，跳过的片段逐一说明原因；用户抽好帧后，它再为该片段重写提示词并生成。（这是场景 15 的早期版本，后来脚本又改过，台词与成片不同。）
