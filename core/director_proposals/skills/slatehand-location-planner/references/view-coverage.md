# 地点图片覆盖方法

地点图片是按需积累的视觉资料，不是必须覆盖全部 Shot 的机位表。优先保存能长期复用的空间信息；没有现成图片时，让 LLM 根据
Scene、地点描述与镜头上下文自行建立画面，不要为了“覆盖率”机械生成图片。

## 何时值得建图

- 空间布局复杂，后续多次回到同一地点；
- 某个角落、固定陈设或状态变化需要明确视觉锚点；
- 用户想先探索气氛、材质或照明；
- 用户希望在全景查看器中自由转动，再手动截取具体视角。

## 普通图与全景图

- 普通图适合明确构图、局部空间、材质细节和状态参考，成本更低，也最常用。
- 全景图适合需要环视的封闭或连续空间，但不是默认主图。只有用户确实需要自由取景时才生成。
- 不为每个 Shot 预建一张图，不预先从全景图派生正反打或其它子图。

## 说明与提示词

`description` 说明图片实际展示什么；`prompt_text` 说明下一次想生成什么。两者必须分开维护。采用候选后检查真实结果，修订
`description` 中的可见方位、陈设、材质、光线与状态，避免把未生成成功的意图当成事实。

## 参考图

一次地点图片生成可显式选至多 5 张任意项目图片。只选择对本次生成有实际价值的参考，并在正文中分清它们提供的是空间布局、
材质、状态还是风格；不要因为图片同属一个地点就自动全部提交。
