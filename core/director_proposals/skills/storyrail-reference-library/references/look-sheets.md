# 造型与造型图

造型是角色图的唯一单位：每套造型有名称、外观、使用场合和一张由用户选定的造型图。Keyframe 按造型为每帧选图。

## 增改造型

引用库建立后，用户要求新增或修改造型时用 `edit_looks`，`operations` 为 1–32 个操作：

- `{"op": "add_look", "character_id", "name", "appearance", "usage"}`：给出镜角色新增一套造型，Core 分配造型 ID；
- `{"op": "update_look", "look_id", "fields": {...}}`：`fields` 是 `name` / `appearance` / `usage` 的非空子集。

字段含义同 [card-contract.md](card-contract.md)。改造型文字不会作废已选造型图；外观变化较大时向用户说明旧图
已不匹配，由用户决定是否重新生成。删除造型、选定造型图只由用户在角色卡上完成。

## 设定图

造型图可以是用户从资产库选的图片，也可以是 Core 生成的设定图（固定 2:1，柔和浅灰底）：左侧约四分之三为同一主体的
正面、正侧、背面与最能展示形态的第四个角度（人形取四分之三侧，伏地或多足生物取俯视），右侧约四分之一为头部正面特写。
版式不预设人形：主体完全由 `visual_description` 与 `appearance` 决定，非人生物会被要求按真实生物绘制、只画主体本身。
因此非人类角色的视觉描述必须写清物种与身体结构，造型外观不得写姿态或所处环境。

提示词由 Core 按角色 `visual_description` 与造型 `appearance` 编译，画幅、分辨率与版式也由 Core 处理，
Agent 不写设定图提示词；用户可以在角色卡上查看并编辑完整提示词后生成。

只有用户明确要求时才生成：`generate_media` 使用 `kind: "look_sheet"`、`target_id` 为造型 ID、
`identity_asset_ids` 为身份参考图（0–4 张项目图片 Asset，可为空列表）。身份参考只保持脸部、体型与年龄感，
服装发型以本造型为准：

- 角色第一套造型通常不带身份参考，或只带用户提供的角色照片；
- 第一套造型图被用户选定后，同一角色其余造型带上它作为身份参考，保证多套造型是同一个人。

每次调用只新增一张候选；用户想多看几张时多次调用。生成后用 `manage_generation` 的 `wait` 观察，
完成后请用户在角色卡上选择——造型图的选择只由用户完成，Agent 不能代选。
