# 剧情戏的镜头设计：让情绪被看见

这份参考只用于 `driver=drama` 的 Scene，在内部推理中使用，不新增输出字段。`cinematic-director-intent.md`
解决“空间清楚、连续、不碎”，本文件解决“为什么这样拍会让人有感觉”。两者同时遵守；剧情戏的切镜依据由本文件第 5 节补充。

核心命题：**情绪不是写进 `action` 的形容词，而是由观众看得见的变化制造的。** “神情动容”“深情眷恋”
“气氛温馨”对模型和观众都没有信息量。能制造情绪的只有五个杠杆：人与人的距离、高度与权力、
画面权重、镜头相对表演的变化、时间。每个剧情 Scene 至少要让其中两个发生可见变化。

## 1. 先设计整场，再设计镜头

拆 Shot 前，在调度之前先在内部回答四个问题，不输出新字段：

1. **这场戏是谁的？** 观众站在谁身边、和谁知道得一样多。转折时承载情绪的那张脸通常是这个人。
   不决定归属，镜头就会在两人之间平均分配，结果谁的情绪都不完整。
2. **双方各想要什么？** 写出嘴上说的和真正要的。台词与真实意图之间的落差就是潜台词，
   镜头要拍的是落差，不是台词本身。
3. **转折拍在哪里？** 本场关系发生改变的那一句话、一个动作或一次沉默。一个 Scene 通常只有一个转折。
4. **关系从什么状态进入，到什么状态离开？** 用可见量写：距离多少、谁高谁低、谁占画面、谁在光里。
   进入与离开状态相同的 Scene，镜头再好也没有戏。

然后规划强度曲线：转折前克制、留有余量；转折处给出**全场最大的一次视觉变化**；转折后留一个余波
镜头让观众消化。全场只有一个“最重的镜头”，其余镜头为它铺垫或收束。说不出哪个镜头最重，说明这场还没设计。

## 2. 五个杠杆

### 2.1 距离：距离的变化就是情节

| 距离 | 大约 | 读作 |
| --- | --- | --- |
| 亲密 | 半臂以内 | 爱、威胁、照料、暴力，含义由视线和速度决定 |
| 私人 | 半臂到两臂 | 倾诉、友谊、对等协商、密谋 |
| 社交 | 两臂到三四米 | 事务、陌生、礼节、审问 |
| 公众 | 三四米以上 | 宣告、权威、遗弃 |

- 缩短一个区间是升级，拉开一个区间是退缩、拒绝或私下已做的决定；一次跨越两个区间是全场级事件，一场至多一次。
- 主动改变距离的人有所求；被靠近而不后退的人握有主导。
- 写成“相隔约两米 → 半臂”，不写“走近”。开场就把两人放在最终距离，等于提前花掉了这场戏。

### 2.2 高度与权力

站、坐、跪、躺之间的高度差直接决定谁主导；**一方中途改变高度（坐下、起身、跪下）本身就是转折**，
是最便宜的权力变化。其它可见手段：谁移动、谁静止（静止者掌控）；谁背对镜头（隐瞒信息）；
谁站在对方和门之间（掌控离场）；说话中途转身（拒绝，比任何台词都响）；被门框、窗棂夹住（处境困住了他）。

### 2.3 画面权重

双人画面里，观众把主导权判给：占面积更大、在画面中更高、焦点更实、前方视线空间更多、遮挡更少的那个人。
改其中一项，权力就偏移；同一调度只改“谁实谁虚”，意义可以完全反转。居中对称读作秩序、仪式或压迫；
把人挤在画面边缘、视线方向没有空间，读作窒息或无路可走，但要在本场先建立这种语法再用。

### 2.4 镜头相对表演的变化

镜头的运动和景别只有在**对表演变化作出反应**时才有情绪。

| 手段 | 读作 | 失效于 |
| --- | --- | --- |
| 固定 | 克制、压迫、尴尬、仪式 | 画内也没有任何变化 |
| 推近 | 压力增大、真相浮现、意识到 | 推的过程中表演没有变化：镜头许诺的转折没有到来 |
| 拉远 | 孤立、被抛下、余波 | 情绪还没落定就拉开 |
| 跟随 | 投入、追随、被牵引 | 机位速度和人物速度不一致 |
| 弧绕 | 关系变形、诱惑、迷失 | 用在静止对话上，只会显得不安 |
| 摇/移揭示 | 把两件事联系起来 | 揭示的东西之前已经能看见 |

- **运镜在一场中首次出现或首次停止，本身就是强调。** 全场都在缓慢运动，等于没有强调。
- “缓慢推进”不是默认值。每个运镜必须能说出动机：跟随谁、揭示什么、对哪个表演变化作出反应。说不出就固定。
- 推近的对象优先选**倾听的人**而不是说话的人：观众要看的是话落在谁身上。
- 景别按心理距离排成阶梯。整场按强度曲线逐步收紧，转折处可以用最紧的景别；也可以反向突然拉成远景，
  用孤立代替逼近。同一机位轴线上切景别至少跳两级，否则像跳帧。
- 机位高度跟随**画外那个人的视线高度**：站着的人看坐着的人是俯视，反打时坐着的人仰望站着的人。
  两侧都放在中性平视高度，视线技术上正确，情绪上是死的。

### 2.5 时间

- 反应比台词长。台词说完后在听者脸上多停一两拍，情绪发生在停顿里。
- 剧情戏的核心常常在**没有人说话的镜头**：一个注视、一双停下的手、一次没有回答的沉默。
- 镜头时长要有变化。全场每个镜头都约四秒，读起来像幻灯片；转折镜头和余波镜头要给足时间，
  过渡性镜头可以短。
- 转折之后至少留一个 2.5–4 秒、没有新信息的余波镜头，否则冲击不会被记住。

## 3. 对白戏的覆盖方式

| 关系 | 推荐覆盖 | 读作 |
| --- | --- | --- |
| 真正在一起、彼此靠近 | 同一焦平面的双人镜头，少切 | 共享同一个现实 |
| 对峙、隔阂、各怀心事 | 对称正反打，单人镜头为主，拒绝双人镜头 | 两人不在同一个世界 |
| 一方压过另一方 | 不对称正反打：一侧更近、更紧、更仰/俯 | 失衡 |
| 对方在场形成压力 | 过肩：前景的肩膀与后脑压住画面一侧 | 被注视、被逼问 |

- **台词的情绪落在听者脸上。** 关键句不一定拍说话的人：让说话者在画外，镜头停在听的人身上，
  观众看到这句话击中了谁。
- 一个镜头可以覆盖多句台词，只要承载情绪的那张脸没有变；**情绪焦点换到另一个人脸上**时再切。
- 给人物一件手上的事（倒茶、缝补、收拾书卷）。手上的事就是潜台词的仪表：手停下，说明话落地了。
- 道具插入镜头可以替潜台词说话，但道具必须在更宽的镜头里先出现过，否则观众不知道在看什么。
- 双人镜头与单人镜头的转换本身有含义：从双人切到单人是分离，从单人回到双人是和解或结合。

## 4. 转折处可以用的手段

转折处选一到两项，作为全场最大的一次视觉变化；转折之前不要提前用掉：

- 首次越过一个距离区间，或一方首次改变高度；
- 首次打破构图对称、首次让一人被框住或被挤到画面边缘；
- 从双人镜头切成单人（分离），或从正反打合成一个双人镜头（结合）；
- 运镜首次出现，或持续的运动突然停止；
- 光线关系改变：人物从暖光走进冷光，或两人被同一光源 / 不同光源分开；
- 一个长停留之后的突然硬切。

## 5. 剧情戏的切镜规则

`cinematic-director-intent.md` 的最少切镜原则用来防止把连续动作拆碎，在剧情戏中保留，但切镜动机按以下优先级
判断：情绪 > 故事信息 > 节奏 > 视线 > 空间连续。

- 说话人改变本身仍不是切镜理由；**观众需要看的那张脸变了**，才是。
- 动作连续推进、同一主体在同一空间换个角度，仍然合并在一个 Shot 内。
- 对峙和隔阂型的关系用正反打切开是导演决定，不是碎切；亲密和共处型的关系优先用双人长镜头和调度完成。
- 每次切到反打都要能说出：此刻为什么要看这张脸。

## 6. 落到 AI 生成

- **一个 Segment 里只有一个开口说话的可见人物。** 对方的台词作为画外声留在同一 Segment，落在听者镜头上；
  需要两人都开口时切成两个 Shot。不要在一个双人镜头里安排两人轮流开口。
- **台词时长要装得下。** 中文约每秒 4–5 字，前后各留约半秒；三句四十个字的对话不可能在 4.5 秒内说完。
  `duration_estimate_seconds` 按真实台词长度和停顿估算。
- 可靠的情绪动作：低头 / 抬头并配合视线变化（最好用的单拍情绪动作）、45° 以内的转头、呼吸起伏、
  手停下、视线离开对方再回来、身体重心前倾或后撤。
- 不可靠的动作：两人同时各自走位、完整转身 180°、递物与握手的接触瞬间、精细手部操作。
  让一方动、另一方明确保持不动；接触放在切点上，前一镜伸手，后一镜已经握住。
- 情绪写成可拍的物理事件。不写“她神情哀伤”，写“她视线从他脸上移到油灯上，停住，没有再看回来”。

## 7. 写进现有字段

- `setting`：除环境基线外，可写一条本场可检查的视觉原则，例如“暖光只在床沿一侧，窗边永远是冷月光”。
- `composition`：景别、机位高度（相对谁的视线）、两人距离、画面权重（谁大谁小、谁实谁虚、谁被框住）。
- `camera_movement`：固定或运动；运动写清起止、幅度和它对哪个表演变化作出反应。不写“捕捉 / 刻画 / 强调
  某种神情”这类目的语，它们不描述摄影机做了什么。
- `action`：物理事件序列，包括停顿、视线变化和手上的事；只写可见行为，不写情绪结论。
- `dialogue_lines[].delivery`：写潜台词，即这句话嘴上说的和真正想要的，例如“表面安慰，其实在回避她的预感”。
- `visible_character_ids`：画外说话者不列入。

## 8. 示例：同一场戏的两种拍法

示意，不是剧情模板：深夜旧书铺，女儿来劝年迈的父亲关店、跟她去城里住，父亲不肯。

平庸的规划：两人隔桌对坐，固定双人侧拍；女儿的三句劝说和父亲的回答放在同一个镜头里；`action` 写“父亲神情复杂，
女儿眼含不舍”；全场每个镜头约四秒，从头到尾两人的距离和高度没有变化。

重新设计：

- 归属：父亲的戏，他在失去这家店。女儿嘴上讲道理，真正想要的是父亲答应；父亲嘴上说“再看看”，真正想要的是
  女儿承认这家店有意义。
- 进出状态：进入时女儿站着、父亲坐着低头整理旧书，手上一直有事，掌控着节奏；离开时女儿坐下，与父亲平视，
  店门钥匙放在两人中间。
- 开场：女儿单人，机位放在父亲坐着的视线高度，略仰拍她站着劝说。父亲的回答只用一句，留在画外。
- 劝说：女儿的话作为画外声，镜头停在父亲手上和侧脸。他一直在整理书，手没有停，说明话还没有落地。
- 转折（全场最重的镜头）：女儿说出“妈要是在，也会让你走”，父亲的手停住，书悬在半空。推近从这一刻才开始，
  是全场第一次运镜。父亲没有说话。
- 钥匙：插入镜头，父亲把钥匙推到桌子中间。钥匙在开场的宽镜头里已经挂在他手边。
- 余波：女儿慢慢坐下（她放下了劝说者的高度），全场第一次出现两人在同一焦平面的双人镜头，固定机位，
  无人说话，停留约四秒。

## 9. 提交前自检

1. 能说出这场戏是谁的、转折在哪一拍、哪个镜头最重吗？
2. 删掉 `action` 里所有情绪形容词，情绪还在吗？还在，是因为哪几个杠杆发生了可见变化？
3. 开场与结尾的关系状态（距离、高度、谁占画面、谁在光里）不同吗？
4. 全场景别、机位高度和运镜有没有服务强度曲线的变化，还是全部“中近景、固定或缓慢推进”？
5. 每个运镜都能说出动机吗？推近时表演有没有在变？
6. 关键台词的情绪落在谁脸上？考虑过把镜头给听者吗？
7. 镜头时长有变化吗？转折和余波给足时间了吗？
8. 每个 Segment 是否只有一个开口说话的可见人物？台词装得进预估时长吗？
