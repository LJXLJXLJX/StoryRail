# 专业关键帧设计参考

这份参考用于把已批准镜头落实为足以约束整段视频的静态边界。先检查连续过程与视觉信息覆盖，
再细化单张构图；不能擅自重新导演整场戏。

## 0. 先设计连续过程，再选择图片

先在完整 Scene 内区分切镜和一镜到底，按连续组推演摄影机、人物与道具的起止状态。
例如“电台特写 → 拉远露出人物 → 绕至肩后”，每个交接只设计一个共同画面，景别变化发生在段内。
不能将三个独立代表构图直接当作无切镜的交接；如果已批准脚本要求机位瞬间跳变，应先明确脚本冲突。

先读取 `video_inputs` 的当前 recipe、合法帧策略和显式媒体绑定。对每个 Segment 分开列出身份/空间等参考需求与必须精确锁定的时间边界。
独立参考能提供视觉信息，但不规定它必须出现在首尾哪一时刻；角色卡与生图辅助图不自动进入视频请求。
先判断是否需要首帧，再要求尾帧具有独立必要性；普通表情、小动作和人物进出由视频模型实现，不自动增加尾帧。

| 内容 | 帧选择依据 |
| --- | --- |
| 人物和场景已交代，小幅动作/表情变化 | 通常单首帧，尾帧须有独立时间约束 |
| 已有独立视觉参考、无需精确起止画面 | recipe 允许时使用 none；缺素材先规划/添加参考 |
| 局部拉远，揭示人物和房间 | 结合独立参考判断，需精确锁定两端构图时使用双帧 |
| 全景推近同一主体 | 可用全景首帧；必须精确结束构图时补尾帧 |
| 一镜到底内部分段 | 后段启用首帧；前段尾帧按需 |
| 固定镜头且状态近似 | 没有独立结果或边界约束时，不为凑首尾生成两张近似图 |

不能把全景图冒充实际特写起点，也不能为省图删去剧情所需的揭示。双帧之间出现但两端都未覆盖的重要
内容仍是缺口，不能宣称双帧必定足够；分段或镜头回改必须经 Director 显式处理。

## 1. 从镜头功能出发

先在内部确定镜头功能，例如：建立空间、揭示线索、展示反应、改变权力关系、完成动作或制造悬念。
关键帧的第一视觉重心必须服务这个功能。若一个画面试图同时承担五件事，结果通常只会平均而平庸。

对每个边界问：观众在这一瞬间必须获得的新增信息是什么？答案应该对应一个可见对象、姿态、关系或
空间变化，而不是“紧张”“悲伤”之类不可直接看见的形容词。

## 2. 用几何关系写构图

专业构图不是罗列主体，而是规定关系：

- 主体位于画面的哪一部分，占据多大比例；
- 前景是否遮挡或框住主体，中景承载什么，背景提供什么地点信息；
- 角色之间是并列、对峙、包围、隔离还是前后压迫；
- 视线落向哪里，画外空间留在哪一侧；
- 哪条线条、亮度或色彩关系把目光引向叙事重点。

避免机械套用三分法。居中可表达稳定、仪式或压迫；边缘可表达疏离或即将离场；大面积负空间可承载
画外威胁或下一步运动。构图规则只为叙事关系服务。

## 3. 先调度，再放摄影机

先冻结演员和道具的舞台状态：脚下位置、身体朝向、视线、重心、手部、接触点与遮挡层级。随后根据
已批准的 Shot 构图和角度决定摄影机看到什么。这样能避免提示词只有“近景、低角度”，却没有戏剧关系。

关键动作不要冻结在最不可读的一毫秒。选择动作前的蓄势点或动作后的完成点，保证轮廓与因果关系清楚。
手部交互、多人拥挤或复杂遮挡尤其应选择稳定姿态。

## 4. 连续性分两层

**世界状态连续**包括人物位置、动作方向、视线、道具、服装、光线和天气连续。大多数剪辑只要求这一层。

**像素边界连续**要求摄影机和画面状态也完全相同，才能复用同一张关键帧，适合相邻 Segment 延续同一镜头；
默认的两个独立边界（上一段尾帧、下一段首帧）只要求世界状态连续。共享边界不适合正反打、直接切换机位或蒙太奇。
段内连续推近、拉远、绕行可以改变机位和景别，不是拒绝共享边界的理由。共享图片后仍需检查动作阶段和运动方向，
不能保证运动自动无缝。

一个 Segment 覆盖多个 Shot 时，首帧对应第一个 Shot 的开头、尾帧对应最后一个 Shot 的结尾；中间镜头不画帧，
靠段内软切点与首尾图片约束整段。相邻 Segment 是否共享边界 Shot 决定默认 `continues_from_previous`。

检查：

- 动作跨切时，使用动作前与动作后两个清楚状态，不制造方向反转；
- 对话正反打维持视线方向和轴线关系，但不要声明两帧相同；
- 道具的位置、朝向、开合与持有者不能无故变化；
- 主光方向和时段不能在连续空间中跳变。

## 5. 机位与地点事实

地点库提供空间描述、固定陈设、主光、状态和独立图片说明，不提供 Shot/Keyframe 机位绑定。每张帧必须从已批准的 Shot 构图与动作
自行确定摄影机看到哪一侧空间，并让不同帧中的固定事实一致。

- **同方向判断看背景**：通过可见墙面、陈设、入口与主光判断朝向；景别推拉、角度高低和表演变化不能让空间结构无故翻转。
- **段内转向**：分别写清首尾时刻能看见的空间关系，不要求地点库预先存在对应图片。
- **正反打**：根据轴线推导两侧背景和人物左右关系，不让两个相反方向出现同一组背景。
- **地点图片只作资料**：从 `description` 理解其实际内容；除非人把已选 Asset 显式加入辅助参考，它不会进入生图调用，也不规定机位。
- **没有图片仍可工作**：依据地点文字、Scene setting 和镜头设计建立完整环境，不把地点图片缺失当成阻塞依赖。

## 6. 原生画幅设计

### 16:9

适合表现横向距离、多人关系、环境宽度和侧向运动。不要因为空间宽就让主体过小；第一视觉重心仍应明确。

### 9:16

优先利用前中后景、上下层次、门窗和走廊等纵向结构。多人可采用纵深错位，而非横向排队后裁切。
重要面部、手部和道具尽量留在中间安全区域；顶部与底部为界面遮挡预留余量。横向快速运动需要更早
给出进入空间，避免主体立即撞出画面。

### 2:1

比 16:9 更宽更扁。可用左右分区并置两个主体、让环境横向延展，或用前景遮挡收窄有效画面；单人近景要主动安排横向负空间和视线方向，不要把人物孤立在中间、两侧空洞。垂直空间有限，全身站姿和高处信息需要更远景别或机位高度来容纳，不能指望先按 16:9 构图再裁掉上下。

## 7. 为生成模型降低歧义

- 每个角色只写一个明确位置和一个明确姿态，不给互斥指令。
- 需要识别身份时写可见特征和关系，但只引用该帧真正出现的角色。
- 光学参数按 `cinematic-frame-prompting.md` 写：先写可以直接看见的效果，需要锁定光学观感时补充焦段
  与光圈，不堆没有说明作用的参数。
- 光线写来源与方向，例如“右后方窗光勾出轮廓”，而非只写“戏剧光”。
- 写少数与本帧朝向有关的固定锚点及相对位置，既保持地点一致，也避免堆砌装修清单。
- 关键帧只描述当前静止状态；运动轨迹留给视频提示词。

## 8. 输出前检查

1. 这张帧的叙事重点能否在一眼内辨认？
2. 去掉抽象形容词后，画面仍然具体吗？
3. 人物和道具在空间中的关系是否唯一、无歧义？
4. 它是否尊重前后镜头的轴线、视线、方向和世界状态？正反打背景是否符合各自拍摄方向？
5. 所有一镜到底交接是否共用并启用同一边界？
6. 视觉信息是否有相应视频输入作为依据，且没有把生图参考误当成视频输入？
7. 每张边界帧是否有独立必要的时间约束？每张其他图片是否补充了尚未覆盖的信息？

以上是计划检查，不是对生成结果的看图审核。实际候选遗漏人物或环境时，必须先审核和修正，不能把计划
文字当作真实图片内容。不得因规划通过就自动生成视频。
