# 视频提示词画面与调度规范

## 1. 格式以官方 guide 为唯一来源

字段名、章节顺序、图片对齐句、引用标签与时间语法一律以 `base-en.txt`（T2VA/I2VA/FL2VA/L2VA）或
`ref-en.txt`（Ref2VA）为准。本文件只补充画面与调度的判断，不新增字段、不新增时间戳语法。

## 2. 单镜节拍

- 4 秒以上的单镜写 2~3 个连续阶段：起势（从首帧状态启动，写清机位运动与速度）→ 物理交互与阻力
  （角色动作推进或事件爆发）→ 落点或悬念（减速定焦关键物证，或光影突变）。
- StoryRail 的 Segment 是连续镜头：节拍通过机位运动与动作推进表达，不虚构段内切镜，也不为凑节拍硬写
  切镜。
- 确需切镜时只按官方 `[Shot N] At MM:SS.mmm` 语法，并且只落实已批准的镜头设计；不得用假切镜掩盖
  脚本冲突。

## 3. 运镜与时长

- 运镜按官方三维语法写清运动方式、幅度与速度（Motion Type + Amplitude + Speed）。
- 节拍与 `duration_seconds` 匹配：短片段不硬堆三个阶段，长片段不整段匀速死推。
- 结尾落在可剪辑状态：动作结果清楚，或明确停在下一段的起势之前。

## 4. 画面具象化

- 年代与实体按已确认设定正向锚定；最容易被模型替换的实体可以在正文尾部写与已确认设定一致的排除句，
  不得借机新增用户没有要求的排除项。
- 不露脸角色用装备状态表达反应（护目镜反光弧线、面罩呼吸阀冰霜），不使用瞳孔、下颌等微表情描写。
- 写具体材质、光源方向与空气介质（体积雪雾、悬浮微尘），禁止“电影感、史诗感、高质量”等空词。
- 视频正文与关键帧正文同源：只描述已确定的可见状态如何连续变化，不重新发明画面事实。

## 5. 声音

独立旁白与 BGM 的完整政策见 SKILL.md 的「StoryRail 独立旁白隔离」。这里只强调：`overall_soundscape`
必须写出与画面动作、环境对应的具体音效，不得只写“环境音”或省略。

剧情对白按工作集 `segment.dialogue[].on_screen` 区分：

- `on_screen=true`：该角色在画面中开口，按官方 guide 的说话者 ID 与 `<d>` 格式写口型台词。
- `on_screen=false`：画外台词，说话者不在画面里。仍给稳定说话者 ID，写明是画外、同一空间内的角色声音，
  不用旁白专用的 `says in an off-screen voiceover`；同时写清画面中可见的听者双唇闭合、不说话，
  以及这句话落下时听者的可见反应（视线、呼吸、手上的动作是否停下）。这是脚本有意安排的倾听者镜头，
  不要把说话者补进画面。
- 画外说话者没有绑定音色参考时，跨 Segment 音色可能漂移；需要稳定音色时提醒用户用 Ref2VA 绑定参考音频。

## 6. 一个微示例（通用）

- 匀速死推：`[Shot 1] 镜头缓慢推进，人物站在甲板上。` —— 8 秒里只有一个状态。
- 三节拍：`[Shot 1] 镜头从人物背后小幅推进，风衣被横风掀起；中段人物抬手按住胸前仪表，冷光在手套
  皮革上亮起；最后镜头减速定焦在仪表读数上，背景风暴持续。` —— 三个阶段都有可见变化，且没有段内
  切镜。

## 7. 提交前自检

1. 字段、标签、对齐句与时间语法是否照官方 guide？
2. 是否出现段内切镜、伪造时间或与已批准镜头设计不符的切镜？
3. 节拍数量与时长是否匹配？
4. 旁白隔离与 BGM 政策是否满足？
5. 空泛形容词是否清零，声音是否有具体内容？
