# 视频提示词画面与调度规范

## 1. 格式以官方 guide 为唯一来源

字段名、章节顺序、图片对齐句、引用标签与时间语法一律以 `base-en.txt`（T2VA/I2VA/FL2VA/L2VA）或
`ref-en.txt`（Ref2VA）为准。本文件只补充画面与调度的判断，不新增字段、不新增时间戳语法。

## 2. 单镜节拍与多 Shot 段内切镜

- `context.shots` 只有一项时，Segment 是连续镜头：节拍通过机位运动与动作推进表达，不虚构段内切镜，
  也不为凑节拍硬写切镜。4 秒以上的单镜写 2~3 个连续阶段：起势（从首帧状态启动，写清机位运动与速度）
  → 物理交互与阻力（角色动作推进或事件爆发）→ 落点或悬念（减速定焦关键物证，或光影突变）。
- `context.shots` 有多项时，按数组顺序写 `[Shot 1]`、`[Shot 2] At MM:SS.mmm, …`，每个 Shot 只落实
  已批准的构图、动作与声音方向。切点按各 Shot 的内容与 `duration_seconds` 的比例估算，是软约束：
  Core 不按 Shot 切视频、不记录段内切点，生成后切点漂移仍是合格候选，由人挑选或重生成。
- 段内切镜数当前不超过 3 个；更多切镜先与用户讨论拆成多个 Segment，不靠堆假切镜掩盖脚本冲突。
- 首尾 Picture 只锚定第一个 Shot 的开头与最后一个 Shot 的结尾；中间 Shot 的人物身份、服装、道具与
  空间关系靠参考图和已批准关键帧维持。Ref2VA 时优先建议为可见角色绑定造型图，但仍只在用户明确要求时
  修改绑定。
- 同一句台词跨越段内剪辑时，在两侧连接点用 `<scenetrans>` 并写明音频连续。

## 3. 运镜与时长

- 运镜按官方三维语法写清运动方式、幅度与速度（Motion Type + Amplitude + Speed）。
- 节拍与 `duration_seconds` 匹配：短片段不硬堆三个阶段，长片段不整段匀速死推。
- 结尾落在可剪辑状态：动作结果清楚，或明确停在下一段的起势之前。

## 4. 画面具象化

- 年代与实体按已确认设定正向锚定；最容易被模型替换的实体可以在正文尾部写与已确认设定一致的排除句，
  不得借机新增用户没有要求的排除项。
- 不露脸角色用装备状态表达反应（护目镜反光弧线、面罩呼吸阀冰霜），不使用瞳孔、下颌等微表情描写。
- 写具体材质、光源方向与空气介质（体积雪雾、悬浮微尘），禁止“电影感、史诗感、高质量”等空词。
- 视频正文与关键帧正文同源：只描述已确定的可见状态如何连续变化，不重新发明画面事实。

## 5. 声音

独立旁白与 BGM 的完整政策见 SKILL.md 的「StoryRail 独立旁白隔离」。这里只强调：`overall_soundscape`
必须写出与画面动作、环境对应的具体音效，不得只写“环境音”或省略。

剧情对白按工作集 `segment.dialogue[].on_screen` 区分。`on_screen` 是覆盖 Shot 的并集：`true` 表示
说话者在段内至少一个 Shot 可见，具体在哪一镜开口按该 Shot 的 `visible_character_names` 落实。

- `on_screen=true`：该角色在画面中开口，按官方 guide 的说话者 ID 与 `<d>` 格式写口型台词。
- `on_screen=false`：画外台词，说话者不在画面里。仍给稳定说话者 ID，写明是画外、同一空间内的角色声音，
  不用旁白专用的 `says in an off-screen voiceover`；同时写清画面中可见的听者双唇闭合、不说话，
  以及这句话落下时听者的可见反应（视线、呼吸、手上的动作是否停下）。这是脚本有意安排的倾听者镜头，
  不要把说话者补进画面。
- 画外说话者没有绑定音色参考时，跨 Segment 音色可能漂移；需要稳定音色时提醒用户用 Ref2VA 绑定参考音频。

## 6. 一个微示例（通用）

- 匀速死推：`[Shot 1] 镜头缓慢推进，人物站在甲板上。` —— 8 秒里只有一个状态。
- 三节拍：`[Shot 1] 镜头从人物背后小幅推进，风衣被横风掀起；中段人物抬手按住胸前仪表，冷光在手套
  皮革上亮起；最后镜头减速定焦在仪表读数上，背景风暴持续。` —— 三个阶段都有可见变化，且没有段内
  切镜。
- 两镜段内切镜：`[Shot 1] 中景，甲停在舱门边抬手示意。 [Shot 2] At 00:04.000, 切到乙的正面特写，
  乙抬眼。` —— 4 秒来自两个 Shot 的时长比例，是软约束，不要求生成结果精确落在这一帧。
- 台词跨剪辑：在切口两侧用 `<scenetrans>`，并写明台词从上一镜连续落下，不重新起句。

## 7. 提交前自检

1. 字段、标签、对齐句与时间语法是否照官方 guide？
2. 单 Shot Segment 是否避免了虚构段内切镜；多 Shot Segment 是否按顺序写 `[Shot N] At`，切点只是按
   Shot 设计与时长比例估算，没有伪造时间或与已批准镜头设计不符的切镜？
3. 节拍数量与时长是否匹配？多 Shot Segment 的段内切镜是否不超过 3 个？
4. 旁白隔离与 BGM 政策是否满足？
5. 空泛形容词是否清零，声音是否有具体内容？
