# 全局生图提示词写作

适用于项目中的关键帧、其他图片、地点普通图与全景图，以及 Playground 中所有支持图片输入的生图或改图能力。
本 Skill 是 Agent 的强制写作规范，不依赖 Qwen、Codex、AGY 或其他图片模型。插件专用 Skill 只补充标签、画幅与模型写法，
不能取消本规范的引用说明和正文对应要求。角色设定图的正文与版式由 Core 编译，不由 Agent 改写。

## 写作前确认实际输入

1. 读取当前插件约定与实际提交清单。关键帧以 `image_inputs` 的 `asset_id`、`label`、`roles` 为准；
   地点图按 `reference_asset_ids` 的实际顺序；其他图片须把角色造型参考和显式辅助参考一起计算。
   编辑底图必须对应真实输入的首张图。同一 Asset 兼有多种用途时按 Core 合并结果说明，不重复编号。
2. 有参考图时必须利用自身多模态能力实际看图，再结合用户意图说明用途。项目用 `read_media_input` 获取图片；
   Playground 以用户提供的可见图片或当前 scope 可用的媒体查看方式为准。获取图片字节或链接不等于已经理解图片。
   文件名、历史提示词、输入来源角色和计划文字不能代替看图，也不能据此编造视觉内容或用途。
3. 没有多模态能力、工具不能返回可见图片或图片读取失败时，明确告知用户无法看图，请用户提供各标签对应图片的
   内容、参考用途、需保留与允许修改的属性。已有充分的用户说明时可据此编写，但必须说明依据来自用户而非亲自看图；
   尚缺必要说明时暂停依赖这些图片的提示词编写与生成，不猜测、不假装已看图，也不自动改成无图生成。
4. 标签沿用当前插件：默认 `<Picture1>`、`<Picture2>`；Qwen 多图用 `<image1>`、`<image2>`，单图用“图片”。
   不照抄示例标签到使用其他标签的插件，不把未实际提交的素材写成输入图。参考增减、重排或造型变化后重新核对标签。
5. 用户指定语言时服从。未指定时遵循当前插件的专用写法，本全局规范不额外规定语言；标签保留插件规定的原样。

## 有参考图：引用说明 + 画面正文

Agent 新写或修改提示词时，必须把以下两部分完整保存到 `prompt_text`，不只写在对话或分析里：

- 开头按实际输入顺序，每张图单独一行：`标签: 用途与保留边界`。只写视觉用途，不写文件名、路径或 Asset ID。
- 空一行后写画面正文，可用“画面正文：”作为标题。正文必须明确引用每张实际输入图的标签，说明如何使用、保留什么、调整什么。
  不能只在引用段列出标签，正文却笼统写“参考图”“参考底图”“场景不变”。
- 将身份、造型、画风、空间、材质、光线、姿态、构图分别判断。只从每张图继承已指定的属性，
  不把“仅参考画风”扩成照搬人物，不把场景参考变成固定机位。
- 以明确的保留与修改指令组织正文；变更构图时交代新的视角、透视、遮挡与露出区域。已有身份图时优先保留身份，
  用正文指定本帧表情、姿态和位置，不重复发明五官、服装或空间事实。
- 编写静态画面，不用时间推进或运动过程代替具体的空间布局；画幅句由 Core 或插件按约定编译，正文不重复写画幅。

Core 只提供图片输入清单并校验显式引用段的标签数量、顺序与正文引用，不把清单、默认用途或参考方式指令拼进最终提示词，
不补写缺失的引用说明。最终引用段与正文来自人或 Agent 保存的完整提示词。无法确定标签对应关系时先读取当前清单，不能编造。

### 多图示例（默认标签）

```text
<Picture1>: 画风参考。采用线条、色彩、材质表现与光影风格，不沿用其中的人物、场景和构图。
<Picture2>: 场景参考。保留建筑结构、固定陈设及其空间关系，机位、景别与主体姿态以正文为准。

画面正文：
采用<Picture1>的线条、色彩、材质表现与光影风格。
以<Picture2>中的空间为场景基础，保留建筑结构、陈设位置及其相互关系。
将摄影机移至控制台内侧，朝向主座，采用平视中近景；控制台边缘位于前景，主座位于画面中央，
背景保留可辨识的立柱与拱窗。根据新机位重新组织透视与遮挡关系，不照搬<Picture2>的原始构图。
```

Qwen 多图将上述标签原样替换为工作集给出的 `<image1>`、`<image2>`；其他插件同理。

### 单图示例（Qwen 的自然指代）

```text
图片: 身份与造型参考。保留主体外观、服装和配饰，姿态与构图以正文为准，不复制参考图背景。

画面正文：
保留图片中主体的身份与造型，将其置于主座中央端坐，双手在胸前抱住书籍，目光朝向镜头。
采用平视中近景，背景依照已批准的场景描述建立，按新构图组织主体与背景的遮挡关系。
```

## 无参考图：只写画面正文

没有任何实际图片输入时，不写引用段、图片标签或“参考某图”的句子。
从已批准事实直接描述媒介与风格、主体状态、前中后景、空间关系、材质与光线。
使用具体、可见且互不冲突的描述；不为填充示例新增角色、道具、机位或剧情。

## 生成前自检

- 有图时每个实际标签是否都出现在引用段与正文中，职责是否明确，是否去掉了文件名？
- 是否真正看过图片？无法看图时是否取得了足够的用户说明，并如实说明信息来源？
- 输入增减后标签是否仍与当前顺序一致？改图底图与仅供参考的图片是否区分清楚？
- 无图时是否直接写正文，没有虚构输入图？
- 是否保留用户指定的语言和领域约束，没有重复画幅句或偷偷改写上游导演设计？
- 只生成用户明确授权的目标。历史正文不符合规范时，在授权范围内显式修订；不批量改写已有项目或候选。
